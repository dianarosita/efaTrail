# efaTrail 0.1.0

* Initial release.
* `efa_trail()`: sequential multi-construct EFA orchestration with an
  iteration log (KMO/Bartlett, factor count, and item removal reasons per
  step).
* `audit_report()`: turns an `efa_trail` object into a text or markdown
  audit-trail report.
* Bundled `synthetic_reading` example dataset (see
  `data-raw/generate_synthetic.R`).
